# Security Policy

## Reporting a vulnerability

Email **hello@supercut.ai** with "Security" in the subject line. Please do not open a public GitHub issue. Include a description of the issue, steps to reproduce, and the potential impact.

## Scope

- This repository: the plugin manifest, MCP configuration and documentation
- The Supercut MCP server at `mcp.supercut.ai`, including its OAuth flow

## Out of scope

- The Supercut web app, desktop app and browser extension. Report these to the same address; they are handled separately from this plugin.
- Cursor itself and other third-party services.
